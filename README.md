
# Calculadora de Proteína

Calculadora de proteína para hipertrofia, desenvolvida para ajudar praticantes de musculação a descobrir sua meta diária ideal de proteína com base em dados pessoais e nível de treino.

🔗 **Acesse a calculadora:** [atualgym.com.br/calculadora-de-proteina](https://atualgym.com.br/calculadora-de-proteina/)

## Sobre o projeto

A **MuscleProt Calc** é uma ferramenta de nutrição esportiva que calcula a quantidade ideal de proteína diária necessária para hipertrofia muscular, considerando:

Peso corporal (kg)
Altura (cm)
Sexo biológico
Experiência com treino (iniciante, intermediário, avançado)
Objetivo (ganho de massa ou déficit calórico / cutting)

## Como funciona

1. O usuário insere seus dados pessoais (peso, altura, sexo)
2. Seleciona o nível de experiência com treino
3. Clica em **"Calcular Necessidade"**
4. A ferramenta retorna:
   - Meta de proteína diária (em gramas)
   - Quantidade estimada por quilo corporal
   - Sugestão de distribuição por refeições (4 ou 5 refeições ao dia)
   - Equivalência em fontes alimentares comuns (frango grelhado, ovos, etc.)

## Exemplo de resultado

Para um usuário de exemplo, a calculadora pode retornar:

**Meta diária:** 135g de proteína
**Referência:** ~1,8g por quilo corporal
**Distribuição sugerida:** ~34g por refeição (4x ao dia) ou ~27g por refeição (5x ao dia)

## Aviso

Os valores fornecidos são estimativas baseadas em diretrizes esportivas gerais. Recomenda-se consultar um nutricionista para uma orientação individualizada.
